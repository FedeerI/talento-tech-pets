# Talento Tech Pets

Proyecto de pre-entrega y eventual proyecto integrador final del curso de front-end JS 2026.

> Sitio de demostración creado con fines educativos para el curso de Talento Tech. Los productos, precios, reseñas y datos de contacto son ficticios.

Sitio publicado: https://fedeeri.github.io/talento-tech-pets/

## Qué incluye

- **Estructura semántica:** `header`, `nav`, `main`, `section` y `footer`.
- **Navegación:** lista desordenada con enlaces internos a cada sección.
- **Productos:** cards organizadas con Flexbox.
- **Reseñas:** sección organizada con CSS Grid.
- **Contacto:** datos del local y mapa en dos columnas con CSS Grid, y Media Queries para adaptarlo a distintos tamaños de pantalla.
- **Multimedia:** imágenes de los productos y mapa incrustado.

## Tecnologías

- HTML5
- CSS
- Google Fonts (Poppins y Open Sans)
- Font Awesome (íconos)
